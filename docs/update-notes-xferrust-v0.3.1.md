# 更新说明 · 下载引擎 XferRust v0.3.1

> 面向普通用户的说明，可直接用于应用更新日志 / Release 说明。技术细节（BEP 编号、错误码、字段名等）已省略。

## 完整版

- **下载引擎升级至 v0.3.1，BT 下载速度大幅提升**：同一种子实测峰值从不到 **1MB/s** 提升到 **17.1MB/s**
- **修复 BT 下载速度远低于其他客户端**：此前 tracker 返回的 IPv6 下载者被整条丢弃、向 tracker 的请求也只走 IPv4；现两者都支持，并同时用 IPv4 与 IPv6 请求 tracker 后合并结果
- **修复 DHT 基本失效**（不依赖 tracker 也能找到其他下载者）：DHT 在 macOS 上必然退回纯 IPv4、查询结果又被静默丢弃；现可正常使用，查询超时由 **10 秒缩短到 3 秒**，启动时寻找节点改为并发，冷启动更快
- **修复 IPv6 网络下 uTP 连接、UDP tracker、BT 入站连接完全不可用**：连接 IPv6 下载者必然失败，并要白等一轮超时才会回退
- **修复 HTTPS 在自签证书 / 企业代理（TLS 拦截）环境下全部失败**：证书校验补齐本机系统根证书，公共网站的校验结果不变
- **修复「no-proxy」设置不生效**：列在该规则里的地址此前仍会走代理，导致本可直连的地址反而失败
- **修复部分文件「进度跑满但文件是坏的」**：开启磁盘缓存时，还没真正写入磁盘的分片被记成已完成，崩溃或断电后恢复会跳过它们、留下空洞；现只有已落盘的分片才计入进度
- **修复 HTTP 分片下载偶尔「一个字节都没下就显示完成」**：此前会留下残缺文件却提示成功，现会正确重新下载并补全
- **修复「只有一个文件的多文件种子」存放位置错误**：文件占用了本该是文件夹的位置，与其他下载软件不一致，也无法继续做种；升级后已下载的数据会**自动迁移**，无需重新下载
- **修复单文件种子的文件路径显示与文件校验**：此前详情页显示的是一个不存在的路径，校验总是报「文件缺失」
- **修复 DHT 对外公布的两处错误信息**：公布的端口没人监听、并把 IPv6 下载者错误地当成 `0.0.0.0` 发给别人（对端会去连接自己）
- **修复 NAT-PMP 的 TCP 端口映射从未生效**（此前只有 UPnP 起作用）：在路由器后面做种 / 接受入站连接更容易成功
- **修复版本号位数增加时（如 0.10.0）引擎崩溃**，以及开启 DHT 持久化后的崩溃
- **其他优化**：正式版构建改为性能优先（BT 收发、文件校验、分片读写更快）；空闲时的磁盘写入与后台唤醒大幅减少，更省电、更少无谓读写

## 精简版（5 条，用于更新弹窗等空间有限的位置）

- 下载引擎升级，**BT 下载速度大幅提升**（实测峰值从不到 1MB/s 到 17.1MB/s）
- 修复 **IPv6 网络下 DHT、uTP、UDP tracker、BT 入站连接不可用**的问题
- 修复文件显示「下载完成」但**内容损坏 / 残缺**的问题（磁盘缓存与断点续传）
- 修复部分种子的**文件存放位置与路径错误**，旧的已下载数据会自动迁移，无需重下
- 修复 **HTTPS 证书、代理直连（no-proxy）、端口映射**等多项设置不生效的问题
